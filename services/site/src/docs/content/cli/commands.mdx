---
title: "Commands"
description: "Reference for the ocnano command line."
---

Every command accepts `--help` for its full flag list, for example `ocnano run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ ocnano run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: OC Nano review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @ocnano/cli
      - run: ocnano run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ ocnano run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ ocnano run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ ocnano run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ ocnano run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ ocnano run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ ocnano run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ ocnano run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `ocnano session list` includes it, and you can open it by ID.

```bash
$ ocnano run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ ocnano run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ OC Nano mini
```

Continue the last session.

```bash
$ OC Nano mini --continue
```

Start with a model and an initial prompt.

```bash
$ OC Nano mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ OC Nano mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ OC Nano mini --help
```

## session

Manages sessions.

```bash
$ ocnano session list
```

Limit the list and print JSON.

```bash
$ ocnano session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ ocnano session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ ocnano session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ ocnano session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ ocnano session import session.json
```

Import into a specific directory.

```bash
$ ocnano session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ ocnano session --help
```

## auth

Manages AI providers and credentials.

```bash
$ ocnano auth list
```

List them as JSON.

```bash
$ ocnano auth list --format json
```

Log in to a provider.

```bash
$ ocnano auth login anthropic
```

Log in with a specific authentication method.

```bash
$ ocnano auth login anthropic --method key
```

Log out of a saved account.

```bash
$ ocnano auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ ocnano auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ ocnano auth export anthropic > credentials.json
$ ocnano auth import credentials.json
```

View all subcommands and flags.

```bash
$ ocnano auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ ocnano mcp list
```

Add a remote server.

```bash
$ ocnano mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ ocnano mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ ocnano mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ ocnano mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ ocnano mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ ocnano mcp logout sentry
```

View all subcommands and flags.

```bash
$ ocnano mcp --help
```


```bash
$ ocnano plugin list --builtin
```


```bash

```

View all subcommands and flags.

```bash
$ ocnano plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ ocnano serve
```

Bind to all interfaces on a fixed port.

```bash
$ ocnano serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ ocnano serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ ocnano serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ ocnano pair
```

Use an external URL in the links.

```bash
$ ocnano pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ ocnano pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ ocnano pair --remote --yes
```

View all subcommands and flags.

```bash
$ ocnano pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ OC Nano service start
```

Restart it.

```bash
$ OC Nano service restart
```

Show its status.

```bash
$ OC Nano service status
```

Stop it.

```bash
$ OC Nano service stop
```

Read a setting.

```bash
$ OC Nano service get hostname
```

Set a setting.

```bash
$ OC Nano service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ OC Nano service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ OC Nano service set env OCNANO_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ OC Nano service unset hostname
```

View all subcommands and flags.

```bash
$ OC Nano service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ OC Nano reload
```

## api

Makes a request to the running server.

```bash
$ OC Nano api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ OC Nano api session.list --param limit=10
```

Send a JSON body.

```bash
$ OC Nano api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ OC Nano api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ OC Nano api --help
```


## debug

Provides debugging and troubleshooting tools.

```bash
$ ocnano debug agents
```

List configuration sources.

```bash
$ ocnano debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ ocnano debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ ocnano debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ ocnano debug paths
```

Print a single path.

```bash
$ ocnano debug paths db
```

View all subcommands and flags.

```bash
$ ocnano debug --help
```

## upgrade

Upgrades OC Nano to the latest or a specific version. Alias: `update`.

```bash
$ ocnano upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ ocnano upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ ocnano upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls OC Nano. Session data, configuration, and
state are not removed.

```bash
$ ocnano uninstall
```

Preview what would be removed.

```bash
$ ocnano uninstall --dry-run
```

View all subcommands and flags.

```bash
$ ocnano uninstall --help
```
