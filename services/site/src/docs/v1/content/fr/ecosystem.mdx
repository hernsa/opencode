Une collection de projets communautaires construits sur OC Nano.

:::note
Vous souhaitez ajouter votre projet lié à OC Nano à cette liste ? Soumettez une PR.
:::

Vous pouvez également consulter [awesome-ocnano](https://github.com/awesome-ocnano/awesome-ocnano) et [ocnano.cafe](https://ocnano.cafe), une communauté qui regroupe l'écosystème et la communauté.

## Extensions

| Nom                                                                                                | Description                                                                                                                            |
| -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |

| [ocnano-helicone-session](https://github.com/H2Shami/ocnano-helicone-session)                  | Injecte automatiquement les en-têtes de session Helicone pour le regroupement des requêtes                                             |

| [ocnano-websearch-cited](https://github.com/ghoulr/ocnano-websearch-cited.git)                 | Ajoute le support natif de la recherche web pour les fournisseurs pris en charge avec le style Google Grounding                        |

| [ocnano-md-table-formatter](https://github.com/franlol/ocnano-md-table-formatter/tree/main)    | Nettoie les tableaux Markdown produits par les LLM                                                                                     |

| [oh-my-ocnano](https://github.com/code-yeongyu/oh-my-ocnano)                                   | Agents d'arrière-plan, outils LSP/AST/MCP pré-construits, agents sélectionnés, compatible Claude Code                                  |
| [ocnano-notificator](https://github.com/panta82/ocnano-notificator)                            | Notifications de bureau et alertes sonores pour les sessions OC Nano                                                                  |
| [ocnano-notifier](https://github.com/mohak34/ocnano-notifier)                                  | Notifications de bureau et alertes sonores pour les événements de permission, d'achèvement et d'erreur                                 |
| [ocnano-zellij-namer](https://github.com/24601/ocnano-zellij-namer)                            | Nommage automatique de session Zellij alimenté par l'IA basé sur le contexte OC Nano                                                  |
| [ocnano-skillful](https://github.com/zenobi-us/ocnano-skillful)                                | Permet aux agents OC Nano le chargement différé de prompts à la demande avec découverte et injection de compétences                   |
| [ocnano-supermemory](https://github.com/supermemoryai/ocnano-supermemory)                      | Mémoire persistante entre les sessions utilisant Supermemory                                                                           |
| [@plannotator/ocnano](https://github.com/backnotprop/plannotator/tree/main/apps/ocnano-plugin) | Révision de plan interactive avec annotation visuelle et partage privé/hors ligne                                                      |
| [@openspoon/subtask2](https://github.com/spoons-and-mirrors/subtask2)                              | Étend OC Nano /commands en un système d'orchestration puissant avec contrôle de flux granulaire                                       |
| [ocnano-scheduler](https://github.com/different-ai/ocnano-scheduler)                           | Planifie des tâches récurrentes en utilisant launchd (Mac) ou systemd (Linux) avec la syntaxe cron                                     |
| [micode](https://github.com/vtemian/micode)                                                        | Flux de travail structuré Brainstorming → Planification → Implémentation avec continuité de session                                    |

| [ocnano-notify](https://github.com/kdcokenny/ocnano-notify)                                    | Notifications natives de l'OS pour OC Nano – sachez quand les tâches sont terminées                                                   |
